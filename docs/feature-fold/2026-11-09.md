## FIX

### ff-2026-11-09-01 · Self-paced sweeps end after iteration 0 under the new `/loop` rule
- **Verdict:** FIX · **Class:** automation
- **Changelog (2.1.319):** "Changed self-paced `/loop` to end when a turn finishes without
  rescheduling, instead of scheduling a fallback wakeup; set `CLAUDE_CODE_LOOP_KEEPALIVE=1` to keep
  the old behavior"
- **Affected files:** `skills/autonomous-sweep-core/SKILL.md:44` ("4. Stop. The next iteration
  starts the work.") and `:53-54` (ends turns to wait on background agents with no wakeup);
  `skills/autonomous-doc-refresh/SKILL.md:34` and `:43-44`, same text. Through the core contract,
  this reaches every detector skill that follows it: brand-scrub-sweep, changelog-refresh,
  config-drift, deadlink-check, deploy-health, license-compliance, security-sweep, test-backfill
  and wip-reconciler.
- **Proposed change:** Make iteration 0 call `ScheduleWakeup` (~60s, same prompt) instead of
  stopping. Add one rule: every turn except the last must reschedule before it ends, including a
  turn that ends to wait on background work (use a 1200s+ fallback there). If you need a stopgap
  before applying, set `CLAUDE_CODE_LOOP_KEEPALIVE=1` in `settings.json` `env`.
- **Risk:** low. It changes prose only, and the change matches what later iterations already do.
- **Test:** In a scratch root with two or three repos, run `/loop /deadlink-check` (self-paced).
  After the ledger is written, the loop should show a scheduled wakeup and go on to row 1 by
  itself. Without the patch, the loop ends after the ledger.
- **Patch:** `docs/feature-fold/patches/2026-11-09/ff-2026-11-09-01.patch` (`git apply --check`
  passes against the mirror).

## ADOPT

### ff-2026-11-09-02 · `permissions.denyInsteadOfPrompting` for unattended loops
- **Verdict:** ADOPT · **Class:** automation (settings)
- **Changelog (2.1.319):** "Added `permissions.denyInsteadOfPrompting` setting: a tool call that
  would wait on a permission prompt is denied and the turn continues, in terminal sessions,
  subagents and teammates"
- **Affected files:** `skills/autonomous-sweep-core/SKILL.md` (sweeps that run overnight under
  `/loop`), `skills/self-improve-loop/SKILL.md`, and `commands/update-docs.md:186` (treats
  `/autonomous-doc-refresh` and `-p` runs as unattended). Today one stray prompt can stall a sweep
  until the owner comes back.
- **Proposed change:** Turn it on for unattended runs: pass it with `--settings` when you start
  a long `/loop` sweep, or put it in a dedicated profile. Do not put it in `~/.claude/settings.json`:
  interactive sessions should still ask. Combine it with last week's
  `blockWritesOutsideWorkingDirectories` (ff-2026-11-02-01) in the same unattended profile.
- **Risk:** low per-run. Global placement would silently deny things you'd have approved.
- **Test:** `claude --settings '{"permissions":{"denyInsteadOfPrompting":true}}'`, then ask for a
  Bash command that isn't allowlisted (e.g. `curl -I https://example.com`). It should be denied
  without a prompt, and the turn should carry on.
- **Patch:** none. The change goes in settings outside the mirror.
